# Dr. Maya Reynolds, PsyD – Therapy Practice Website

A modern, responsive website for Dr. Maya Reynolds, PsyD, a licensed clinical psychologist based in Santa Monica, California, offering therapy for anxiety, trauma, and burnout.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## Pages & Structure

- `/` – Homepage (Hero, About Welcome, Who I Help, Philosophy, Modalities, Approach, Specialties, CTA)
- `/about` – Dr. Maya Reynolds' background, credentials, and story
- `/office` – Santa Monica office space and environment
- `/faq` – Frequently asked questions about fees, insurance, and sessions
- `/contact` – Inquiry form and consultation booking details
